## 1. 信息架构（走查还原）

```
顶栏: Weave · N 个项目 · 设置
左栏(范围): 全局配置 / 项目列表(健康徽标)
中栏(工作区): 分类卡 ×4（文件资产/个性化配置/任务/Weave） ─ Claude|Codex|全部(运行态 tab) ─ 分类内容
右栏(资产库): 跟随当前选择 · 添加文件夹 · 分类可安装模板
```

三层功能对应在 UI 上落点清晰：**通用功能** = 四分类（文件资产/个性化配置/任务/Weave，
文件资产下 Skills|MCP|Plugins 三 tab）；**harness 特性** = 运行态 tab + Codex 占位 +
claude 徽标；**weave 特有** = Hooks 数据流链路、任务事件链、工具箱、插件区。

## 2. 做得好的（保持，勿回退）

1. **空状态文案给「原因+下一步」**：指令池「注入/手动规则命中后会在这里出现待执行
   指令」；资产库「本分类暂无外部可安装模板，切换到 Skills/MCP 分类查看」。
2. **数据流链路画布**（Hooks 内）：事件源→规则→处理器→会话四段配图例，规则节点内嵌
   开关，会话列带改名/投送。
3. **设置弹窗**（批 7 ✓）：Hooks 总开关 + 「规则级开关另控，关闭后规则命中直接短路」
   的层级说明。
4. **健康徽标**（批 8 ✓）：项目行绿点，aria-label「健康检查全部通过」。
5. **工具箱**（批 10 ✓）：内置/外置 provenance、类型徽标、`目标: claude+codex`、
   「同一条扫描管线」副标题。
6. **表单帮助性 placeholder**：`{event}{tool}{file}…` 占位符清单、`逗号分隔，如 Read, Edit, Bash`。

## 5. P3 — 细节打磨

- `favicon.ico` 404。
